# 学习进度面板与智能练习设计

## 目标

让学习者在学习、练习和设置三个入口看到同一份当天进度，并将练习页的默认入口改为一组按学习时机自动挑选、混合题型的智能练习。

## 范围与原则

- 每日新词目标继续沿用现有全局用户设置；每日练习目标新增为同一层级的全局用户设置，默认 20 题。
- 每日计划提示是否显示也是全局用户设置。移动端首次进入当天学习页时提示，桌面端不弹出。
- 所有进度数字按当前用户、当前词本和本地自然日聚合。每日新词目标是用户全局目标，因此面板同时显示当前词本的新词数和全局目标。
- 新功能只读取现有的 `study_logs`、词本统计和薄弱词规则；不改变首页现有的新词、到期复习词、词组卡和巩固测试队列。
- 智能练习默认只从已学习词中选择，优先顺序为：今日新学但尚未练习、到期词、薄弱词、其余已学词。词不够时可重复，但优先保证覆盖。

## 设置与数据契约

`UserSettings` 增加 `daily_quiz_goal`（正整数，默认 20）和 `show_daily_plan`（布尔，默认 true）。`GET/POST /api/settings/` 返回并可部分更新这三个字段；旧客户端仅提交新词目标时必须保持另两个字段原值。

前端 `lib/data/settings.ts` 提供完整的每日设置对象读写，并保留现有 `get/setDailyNewWordGoal` 兼容调用。云端由设置接口持久化，本地由按用户隔离的 AsyncStorage JSON 保存。

`useDailyProgress` 是唯一的前端聚合入口，输出：词本总词数、已学习数、当前词本今日新词数、全局新词目标、今日复习次数、到期数、今日练习完成题数、练习目标和全部完成标识。它在页面获得焦点和词本切换后刷新，失败时保留可恢复的空数据而不阻塞页面。

## 智能练习

`lib/smartPick.ts` 是纯逻辑模块，输入已学习词、日志、进度和目标题数，输出去重优先的词 ID 会话。题型由稳定配额分配：默写 30%、释义选择 30%、例句选择 20%、词组题 20%。例句或词组内容缺失时，将该题位回补到默写或选择，保证练习可开始。

练习页进入时自动加载智能会话。用户仍可打开“自定义练习”并使用现有范围和单题型入口；原来的最近学习复习功能保持不变。`QuizRunner` 接收可选的 `questionPlan`，根据计划生成一题一词的题目并以实际生成题数作为完成目标，结束时回调本次结果。

## 体验组件

- 桌面网页（非 PWA）右下角显示可收起的 `ProgressWidget`，展示今日新词、练习和待复习。
- PWA/移动端顶端显示单行 `MarqueeBar`，只显示当前最需要完成的一个指标；与桌面浮层互斥。
- `DailyPlanModal` 仅 PWA/移动端且当天首次进入学习页时显示，可从设置关闭。关闭记录使用 AsyncStorage 的日期键。
- `Confetti` 作为无外部依赖的轻量动效，在每日全部完成或智能练习完成时显示一次。

## 验收与测试

- 后端测试覆盖默认值、部分更新、非法练习目标和权限隔离。
- 前端纯逻辑测试覆盖每日进度聚合、智能选词优先级、题型配额、缺少词组/例句时的回退。
- TypeScript 类型检查、现有脚本测试、Django 测试和云端 Web 构建必须通过。
- 本次只在功能分支提交；生产迁移和部署另行获得明确执行指令。
